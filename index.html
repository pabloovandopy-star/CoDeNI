    📖 Guía de código
    
  
    El manual de Nilo. Está disponible en cualquier nivel.
    
  
    Secuencias
    
  
    Un programa es una lista de órdenes que se ejecutan una tras otra. Si Nilo gira antes de avanzar, llega a otro sitio: el orden importa.
    
  
    avanzar();
avanzar();
derecha();
avanzar();
    
  
    Variables
    
  
    Una variable es como un espacio dentro de la mochila de Nilo donde puede guardar información. Su valor cambia: troncos sube cada vez que recoges uno.
    
  
    troncos = 0;
recoger();     // troncos = 1
    
  
    Operadores
    
  
    = guarda un valor · + suma · - resta · += suma y guarda · -= resta y guarda.
    
  
    bateria = 10;
bateria -= 1;  // cada paso con la linterna
    
  
    En el juego, la batería baja sola con cada avanzar(); de noche.
    
  
    Condicionales
    
  
    si decide según lo que Nilo ve. sino es el plan B.
    
  
    si(camino_libre) {
  avanzar();
} sino {
  derecha();
}
    
  
    Bucles
    
  
    Repiten una acción sin escribirla muchas veces.
    
  
    repetir(5) {
  avanzar();
}
    
  
    Funciones
    
  
    Agrupan varias instrucciones con un nombre para reutilizarlas: por ejemplo subirMontaña(); podría contener todos los pasos de una subida. (Llegan en la montaña y el mirador.)
    
  
    Optimización
    
  
    Dos programas pueden llegar a la meta, pero el más corto es mejor: da más puntos. Si repites lo mismo, usa un bucle.
